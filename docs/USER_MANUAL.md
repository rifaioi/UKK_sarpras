# User Manual - Aplikasi Sarpras UKK 2026

Selamat datang di Panduan Pengguna Aplikasi Sarana dan Prasarana (Sarpras). Aplikasi ini dirancang untuk memudahkan manajemen inventaris, peminjaman barang, dan pelaporan kerusakan.

## 🔑 Akses Level User

Aplikasi ini memiliki 3 level akses:
1. **Admin**: Kontrol penuh sistem, manajemen user, dan laporan.
2. **Petugas**: Manajemen barang, pemrosesan peminjaman, dan pengaduan.
3. **Member (Siswa)**: Booking barang dan lapor kerusakan aset.

---

## 👨‍💼 Panduan Admin & Petugas

### 1. Manajemen Inventaris
- Masuk ke menu **Sarpras** > **Data Barang**.
- Gunakan tombol **Tambah Barang** untuk memasukkan aset baru.
- Kode barang akan tergenerate secara otomatis sesuai kategori.

### 2. Memproses Peminjaman
- Lihat daftar permintaan di menu **Peminjaman**.
- Admin/Petugas dapat **Menyetujui** atau **Menolak** permintaan peminjaman.
- Pastikan stok barang tersedia sebelum menyetujui.

### 3. Manajemen Pengembalian
- Saat barang dikembalikan, masuk ke menu **Pengembalian**.
- Klik **Proses Kembali**, lalu pilih kondisi barang (Baik/Rusak/Hilang).
- Sistem akan menambah stok secara otomatis jika barang kembali dalam kondisi baik.

---

## 👨‍🎓 Panduan Member (Siswa)

### 1. Meminjam Barang
- Cari barang yang dibutuhkan di menu **Daftar Barang**.
- Klik tombol **Pinjam**, tentukan jumlah dan lama peminjaman.
- Pantau status permintaan Anda di menu **Riwayat Peminjaman**.

### 2. Melaporkan Kerusakan
- Jika menemukan kerusakan aset sekolah, masuk ke menu **Lapor Kerusakan**.
- Isi formulir, pilih lokasi, dan sertakan foto bukti kerusakan.
- Anda bisa melihat respon/catatan dari Admin pada daftar riwayat laporan Anda.

---

## ❓ FAQ & Troubleshooting
- **Lupa Password?** Hubungi Admin sistem untuk reset manual di menu Manajemen User.
- **Stok Tidak Muncul?** Pastikan barang tidak sedang dalam status 'Dihapus' atau belum diinput datanya.
